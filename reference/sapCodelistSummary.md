# Summarise a codelist's content in one line

Summarise a codelist's content in one line

## Usage

``` r
sapCodelistSummary(content)
```

## Arguments

- content:

  The `$content` of a codelist object: a named list of concept sets, or
  `NULL` when nothing has been uploaded.

## Value

A single string, e.g.
`"2 concept sets, 14 concepts: asthma (9), copd (5)"`.
