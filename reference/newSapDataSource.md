# Create a SAP data-source component

Create a SAP data-source component

## Usage

``` r
newSapDataSource(id, name, description)
```

## Arguments

- id:

  Immutable data-source identifier.

- name:

  Display name of the data source.

- description:

  A `data_source_description` object.

## Value

An object of class `sap_data_source`.
